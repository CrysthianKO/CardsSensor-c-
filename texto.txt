1.Instalar dependências básicas:Prerequisito.Garanta que o seu sistema tem as ferramentas de compilação e descompactação necessárias. 
Execute no terminal:
sudo apt install build-essential unzip
2.Baixar o código-fonte:Baixe a versão mais recente direto do repositório oficial do desenvolvedor:
wget [https://github.com/joan2937/pigpio/archive/master.zip](https://github.com/joan2937/pigpio/archive/master.zip)
3.Extrair os arquivos:Descompacte o arquivo baixado e entre na pasta gerada:
unzip master.zipcd pigpio-master
4.Compilar a biblioteca:~1 a 2 minutos.Compile o código-fonte. 
Esse comando vai gerar os binários compatíveis com a arquitetura do seu Raspberry Pi:make
5.Instalar no sistema:Mova os binários compilados para as pastas corretas do Linux (como /usr/local/lib e /usr/local/include)
para que o seu compilador C++ consiga encontrá-los:sudo make installVerification: 
O terminal exibirá mensagens copiando arquivos como libpigpio.so sem apresentar erros (palavra "Error").
